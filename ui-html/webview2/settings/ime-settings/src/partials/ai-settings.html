AI 长句翻译
中文选词先累计到待翻译句子；仅按 Ctrl+Enter 才翻译并上屏。独立于 AI 联想，复用下方 API 配置；先查本地缓存，未命中才请求 AI。

仅简译 / 繁译启用：桌面选中文字后右键点击翻译；网页使用水杉阅读翻译扩展的右键菜单。仅点击翻译才读取与请求，自动识别原文语言；结果显示在浮窗，不修改原应用。普通简 / 繁不监听选区。发送翻译仍只由 Ctrl+Enter 触发。

可选择 185 种语言选项，也可填写其他语言名称。翻译质量和支持程度取决于当前 AI 模型。

点击悬浮栏的「简 / 繁 / 简译 / 繁译」循环切换。原简繁快捷键仍只切简繁。简译 / 繁译模式下，Space / 数字将选中的中文加入待翻译句子；Enter 一次上屏原文，Ctrl+Enter 才查询缓存并翻译上屏。分段输入与等待均不调用翻译 API。Backspace 纠错，Esc 先取消当前拼音、再清空待翻译句子。
